This is a simple Spotify clone that I made while practicing HTML and CSS.

I tried to recreate the basic Spotify interface and make it responsive for different screen sizes. This project is mainly for learning and practicing frontend development.

 What I used
1.HTML
2.CSS
3.Flexbox
4.Media Queries
 * Features*
Spotify-like layout
Responsive design
Sidebar
Music cards
Bottom music player
Works on desktop and smaller screens
Why I made this
I made this project just for practice while learning frontend development.

It helped me understand how to create layouts using HTML and CSS, use Flexbox, and make a website responsive using media queries.
